## Shared contract
Each component takes `{ wallet, refreshTrigger, onChanged }` where needed. `onChanged(message: string)` reports a finished action. `wallet` has this type (the app supplies it; copy the type into `src/lifeline/wallet.ts`):
`{ available: boolean; address: string | null; onArc: boolean; connecting: boolean; error: string | null; connect(): Promise<void>; sendCalls(calls: {to: string; data: string}[]): Promise<string[]>; signMessage(message: string): Promise<string> }`.

All data comes from these endpoints. Use a `const api = (path) => path` base so they are same-origin.

1. `Marketplace.tsx`, heading "Marketplace". `GET /api/x402/discover?limit=20&query=&maxUsd=` returns `{ network, total, services: [{ url, method, description, provider, category, priceUsd, payTo, needsSignIn, quality: { score, samples, poor } }] }`. Search field and rows: provider, description, price, method. Seller record: `samples < 5` shows "no record yet"; otherwise "delivered N%"; `poor` in alarm colour with "not lent against". `needsSignIn` shows "needs sign-in". A Buy button calls prop `onBuy(service)`.

2. `SecuredCredit.tsx`, heading "Deposit-backed credit". `GET /api/secured` returns `{ configured: false }` or `{ configured: true, vault, assetsUsd, creditUsd, controller, pendingWithdrawalUsd, readyAt, line: { totalCreditLimit } }` (`readyAt` is unix seconds; zero-address `controller` means nobody is bound).
   Steps shown one at a time:
   - No wallet: Connect.
   - Unbound: "Use this wallet": `GET /api/auth/wallet/nonce` → `{ nonce }`; `wallet.signMessage("Link this wallet to my Lifeline account.\nNonce: " + nonce)`; `POST /api/secured {action:"link", wallet: address, signature}`; then `POST /api/secured {action:"bind", wallet: address}`.
   - Controller is another wallet: say so and show its short address; no actions.
   - Bound: readouts of deposited USD and credit it adds, amount field, Deposit: `POST /api/secured {action:"deposit", amountUsd}` → `{calls}`; `wallet.sendCalls(calls)`; `POST /api/secured {action:"sync"}`.
   - Withdraw: `POST {action:"withdraw", amountUsd, to: address}` → `{calls}`: two calls. Send only `calls[0]` to ask. While `pendingWithdrawalUsd > 0`, show the amount and time left. After `readyAt`, Withdraw sends `calls[1]`. Cancel: `POST {action:"cancel"}` → `{calls}`. Sync after each.
   Explain in one line: a deposit raises the line; in default it pays the debt; withdrawals wait while drawdowns settle.

3. `LendingPool.tsx`, heading "Lending pool". `GET /api/pool?lender=<address>` returns `{ configured:false }` or `{ configured:true, pool, totalAssetsUsd, cashUsd, outstandingUsd, exposureCapUsd, maxUtilizationBps, utilizationBps, drawableUsd, interestEarnedUsd, writtenOffUsd, lenderAssetsUsd? }`. Readouts; a thin square utilization bar in ink on `--rule`. Deposit and withdraw: `POST /api/pool {action:"deposit"|"withdraw", amountUsd}` → `{calls}`, then `wallet.sendCalls`. State plainly that lenders can lose money if borrowers do not repay.

4. `LendingLimits.tsx`, heading "Lending limits". `GET /api/risk/controls` returns `{ limits: { poolCapUsd, dailyNewCreditUsd, sellerDailyUsd, breakerDefaultRate, breakerMinLoans }, outstandingUsd, lentTodayUsd, loansDue, loansUnpaid, defaultRate, breakerTripped }`. Used-vs-limit rows; if `breakerTripped`, an alarm line: "New credit is paused: too many loans that fell due are unpaid."

5. `CrossChainRepay.tsx`, props `{ agents: {address: string; name: string}[], onChanged }`, heading "Repay from another chain". Agent select; chain select: Ethereum_Sepolia, Base_Sepolia, Arbitrum_Sepolia (show plain names); amount. `POST /api/repay/crosschain {agentAddress, fromChain, amountUsd}` returns `{ success, bridgedUsd, repaidUsd, steps: [{name,state,txHash?}], error? }`. Show the steps; say it can take a few minutes; explain the agent needs USDC on that chain.
